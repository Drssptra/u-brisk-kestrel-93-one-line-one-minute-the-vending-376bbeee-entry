The entry is a single pickup line spoken by a vending machine to a passing human: "You must be exact change, because every time you walk by my slot lights up, my coils start spinning, and my B4 button blushes." It leans on the machine's own world — the coin slot, the coils, the buttons, the exact change — and lands its charm with a blushing B4 button at the very end. `main.ts` writes that exact line to `entry.txt` and prints it to stdout.

## Run it

node main.ts
